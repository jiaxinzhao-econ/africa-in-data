# Africa in Data — African FX Explorer

Static public website source. The repository's controlled builder copies these files and adds an
allowlisted, source-linked dataset under `data/`.

The deployed package is intentionally self-contained and requires no application server or
database. Do not add Internal reports, raw snapshots, local database files, credentials, machine
paths, or unapproved data sources to this directory.

Source data rights remain with the named providers. No open licence for the source observations is
implied by this website.
